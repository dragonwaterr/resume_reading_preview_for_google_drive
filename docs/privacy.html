Privacy Policy – Resume Reading for Google Drive™

Effective date: October 17, 2026 · 한국어

Summary

Resume Reading for Google Drive™ ("the extension") does not collect, transmit, sell, or share any personal data. The developer never receives any information about you or your files.

What is stored

To reopen each PDF at the page you last viewed, the extension stores the following, and nothing else:

  • The Google Drive file ID of each PDF you have read in a preview
  • The page number you last stayed on in that PDF
  • The times that page was last saved and the file was last opened (used to keep the newest value and to remove old entries)
  • Your setting for the "Moved to page N" notice (on or off)

File names, file contents, and account information are not stored.

Where it is stored

  • chrome.storage.local: on your computer, in your Chrome profile.
  • chrome.storage.sync: in your own Chrome sync storage, so your reading positions follow you across your desktop Chrome browsers. This data is handled by Google Chrome sync under your Google account and is never sent to the developer.

Permissions

  • storage: to save the data listed above.
  • Access to drive.google.com: to detect an open PDF preview, read which page is shown, and scroll it to the saved page. The extension does not read file contents, does not call any Google API, and does not send network requests.

Deleting your data

Removing the extension deletes its local data. Data in Chrome sync can be cleared from Chrome settings (You and Google › Sync › Review your synced data › Clear data).

Changes

If this policy changes, the updated version will be posted on this page with a new effective date.

Contact

Questions can be submitted as an issue at github.com/dragonwaterr/resume_preview_for_google_drive/issues.

개인정보처리방침 – PDF 이어보기 for Google Drive™

시행일: 2026년 10월 17일

요약

PDF 이어보기 for Google Drive™(이하 "확장 프로그램")는 어떤 개인정보도 수집·전송·판매·공유하지 않습니다. 개발자는 사용자나 사용자의 파일에 관한 어떤 정보도 받지 않습니다.

저장하는 정보

각 PDF를 마지막으로 보던 페이지에서 다시 열기 위해 다음 정보만 저장합니다.

  • 미리보기로 읽은 PDF의 Google Drive 파일 ID
  • 해당 PDF에서 마지막으로 머문 페이지 번호
  • 페이지를 마지막으로 저장한 시각과 파일을 마지막으로 연 시각 (최신 값 선택과 오래된 기록 정리에 사용)
  • "N페이지로 이동했어요" 알림 켜기/끄기 설정

파일 이름, 파일 내용, 계정 정보는 저장하지 않습니다.

저장 위치

  • chrome.storage.local: 사용자 컴퓨터의 Chrome 프로필 안
  • chrome.storage.sync: 사용자 본인의 Chrome 동기화 저장소. 다른 데스크톱 Chrome에서 이어서 읽기 위해 사용하며, 사용자 Google 계정의 Chrome 동기화가 처리하고 개발자에게는 전송되지 않습니다.

권한

  • storage: 위 정보를 저장하기 위해 사용합니다.
  • drive.google.com 접근: 열린 PDF 미리보기를 감지하고, 보이는 페이지를 확인하고, 저장된 페이지로 스크롤하기 위해 사용합니다. 파일 내용을 읽지 않고, Google API를 호출하지 않으며, 네트워크 요청을 보내지 않습니다.

데이터 삭제

확장 프로그램을 삭제하면 로컬 데이터가 삭제됩니다. Chrome 동기화에 저장된 데이터는 Chrome 설정(나와 Google › 동기화 › 동기화된 데이터 검토 › 데이터 지우기)에서 삭제할 수 있습니다.
